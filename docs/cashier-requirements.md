# Требования для работы проекта Cashier Intelligence

Для полноценного запуска и стабильной работы системы аналитики кассиров (Cashier Intelligence) требуется установить следующие компоненты:

---

## 1. Среда выполнения (Python)

Проект разработан на базе **Python 3.10+**.

* **Windows (с правами администратора):** [Python 3.10.11 (64-bit)](https://www.python.org/ftp/python/3.10.11/python-3.10.11-amd64.exe) — отметьте **«Add Python to PATH»**.
* **Windows (без прав администратора):** используйте `start_new_pc.bat` (портативный Python).
* **macOS / Linux:** `python3 --version` должен показывать 3.10 или выше.

---

## 2. PostgreSQL

База данных **PostgreSQL 14+** обязательна для хранения импортированных отчётов и статусов кассиров.

**Вариант A — Docker (рекомендуется):**

```bash
docker compose up -d db
```

**Вариант B — локальная установка:**

* Установите PostgreSQL и создайте пользователя/БД, либо скопируйте `.env.example` в `.env` и настройте переменные окружения.

Переменные окружения (см. `.env.example`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `POSTGRES_HOST` | `localhost` | Хост PostgreSQL |
| `POSTGRES_PORT` | `5432` | Порт |
| `POSTGRES_DB` | `cashier_db` | Имя базы данных |
| `POSTGRES_USER` | `cashier` | Пользователь |
| `POSTGRES_PASSWORD` | `cashier` | Пароль |

---

## 3. Зависимости Python

```bash
pip install -r requirements.txt
```

### Основные библиотеки:

1. **fastapi** — REST API для импорта и аналитики.
2. **uvicorn** — ASGI веб-сервер.
3. **openpyxl** — чтение Excel-отчётов KPI и реестров штата.
4. **psycopg2-binary** — драйвер PostgreSQL.
5. **pydantic** — валидация входных данных.
6. **python-multipart** — загрузка файлов через API.
7. **pytest** — модульные и интеграционные тесты.

## 5. Входные данные (Excel XLSX)

Система принимает два типа файлов через `http://localhost:8000/dashboard/import.html`:

### KPI-отчёт кассиров
Многострочная шапка, колонки A:AV. Рекомендуемые поля:
* **Ф.И.Ш / ФИО** — полное имя
* **Табельный номер**
* **Лавозим / Должность**
* **БХМ / Филиал**
* **Ишлаган куни** — отработанные дни
* **Юклама** — процент нагрузки
* Операции (Сони / минутда) — БЭК и ФРОНТ

### Реестр штата и статусов
* **ФИО**, **Должность**, **Филиал**
* **Статус** — отпуск (`мехнат.тат.`), декрет (`декрет`), временный (`вakt.`), вакант

Колонки могут быть на узбекском, русском или английском — система автоматически сопоставит их.
